# Прошивальщик SellerCounter

Пустая плата ESP32-S3 (N16R8) → рабочее устройство одной кнопкой, на любом компьютере.

1. Скачай репозиторий (Code → Download ZIP) или `git clone`, распакуй.
2. Подключи плату по USB.
3. Двойной клик: **macOS** — `Прошить плату.command`, **Windows** — `Прошить плату.bat`, **Linux** — `./flash.sh`.

Нужны только Python 3.8+ (если нет, кнопка подскажет или поставит через winget) и интернет в первый раз.
Остальное прошивальщик делает сам: создаёт свою папку `.venv`, ставит `esptool`/`pyserial`, находит или
скачивает образ MicroPython (с проверкой sha256) и прошивку (если рядом нет `firmware/`, берёт с GitHub),
находит плату, стирает flash, прошивает MicroPython, заливает файлы с проверкой sha256 каждого и
перезагружает плату. Перед стиранием просит нажать Enter.

Ключи (через терминал: `./flash.sh --ключ`): `--check` (только проверить), `--files-only` (обновить файлы, ничего не стирая),
`--image FILE` (записать «золотой» образ целиком по адресу 0x0), `--port`, `--yes`.

После прошивки: Wi-Fi-сеть `UBIX Setup` (пароль `12345678`), страница `http://192.168.4.1`.

Если плата не находится: драйвер WCH CH340/CH343 (https://www.wch-ic.com/downloads/category/30.html),
кабель с передачей данных, или зажать BOOT при подключении USB.

Золотой образ с рабочей платы (`esptool read_flash 0 0x1000000 gold.bin`) содержит Wi-Fi и ключи API
владельца — в репозиторий его не класть.
