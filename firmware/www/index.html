Превью экрана

Физического экрана ещё нет — вот что было бы на нём нарисовано.

Пусто или 0 в обоих полях — на экране реальные данные. Настоящий опрос маркетплейсов эти поля не трогают, следующее изменение продаж всё равно перерисует настоящими цифрами.

Фон экрана

PNG ровно под размер активного экрана (сейчас ?). Картинка не редактируется — просто пакуется в чёрно-белый растр по порогу яркости, так что готовь её заранее чёрно-белой. Применяется сразу, без перезагрузки платы.

Маркетплейсы

Уведомления

Общий выключатель — глушит вообще всё: уведомления о продажах, кнопку "Тест" ниже и звук при загрузке/перезагрузке платы. Остальные настройки на этой странице (громкость, мелодии, ночной режим) при выключенном звуке просто ничего не делают, но остаются как есть.

Отдельно от общего выключателя выше — можно приглушить именно писк при включении/ перезагрузке, оставив звук для продаж и кнопки "Тест". Применяется со следующей загрузки платы (сейчас играющий сигнал уже не остановить).

Файлы лежат в /notifications/ на плате. .mid играется как мелодия, .wav — как грубый PWM-звук (сырые 8-битные моно-сэмплы). .mp3 плата декодировать не умеет — сконвертируй один раз на компьютере: ffmpeg -i file.mp3 -ar 8000 -ac 1 -acodec pcm_u8 file.wav

100% — уже физический максимум для мелодий/MIDI (потолок по напряжению GPIO), выше можно только тише. Для .wav значения выше 100% цифрово усиливают тихую запись — чем выше, тем сильнее искажения (обрезание сигнала), это ожидаемо.

На пьезо высокие ноты иногда звучат ГРОМЧЕ на 80-90%, чем на 100% — это резонанс пьезо с гармониками, которые "линейная" кривая на самом верху гасит (физика PWM, не баг). "Без провала" держит громкость монотоннее ценой чуть более тихого максимума. "Аудио-кривая" просто более естественно звучит на слух (как в аудио-потенциометрах), проблему резонанса не решает.

Мелодия по маркетплейсам

Своя мелодия для конкретного маркетплейса — необязательно, "по умолчанию" значит играть общий выбор выше.

Ночной режим

В это время уведомления о продажах не звучат — опрос маркетплейсов и экран это не касается, молчит только звук. Диапазон через полночь (например 22:00 → 08:00) работает как есть.

Настройки

Экран

Смена экрана требует перезагрузки платы — драйвер и распиновка выбираются один раз при старте. Пины у обоих экранов совпадают (см. docs/HARDWARE.md), физически переключать можно без перепайки.

Wi-Fi

Плата подключится к этой сети и будет опрашивать маркетплейсы через неё.
